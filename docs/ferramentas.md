# Ferramentas

JUCESP: Ficha Cadastral Simplificada expõe 1 ferramenta (todas somente leitura).

### 1. `jucesp_ficha_consultar`
**Input**: `login_cpf` (opcional), `login_senha` (opcional), `pkcs12_cert` (opcional), `pkcs12_pass` (opcional), `cnpj` (opcional), `nire` (opcional), `name` (opcional)

Ficha cadastral simplificada de uma empresa na JUCESP (dados de registro por CNPJ, NIRE ou nome).

## Prompts de exemplo

```
Ficha cadastral simplificada do CNPJ na JUCESP
```
